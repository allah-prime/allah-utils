# 2026-06-17 工作日志

## 新增 rsaUtils 独立 RSA 工具模块
- 需求：用户需要一个独立于 cryptoUtils 的纯 RSA 工具（用户口误称"RSA 对称加密"，实际 RSA 为非对称）
- 位置：`src/core/rsaUtils/`
- 能力：encrypt / decrypt / generateKeyPair / sign / verify
- 跨环境：浏览器端基于 jsencrypt，Node 端基于内置 crypto，两端 PKCS#1 v1.5 填充与签名约定一致，密文/签名可互通
- sign/verify 的哈希复用 crypto-js（SHA256/SHA1/MD5），默认 SHA256
- 默认密钥长度 2048（cryptoUtils 原默认 1024）
- 已注册导出：`src/core/index.ts`（default 集合）、`src/index.ts`（深度导出 + RSAHashAlgorithm 类型）
- 已新建 dumi 文档 `index.md`
- check-exports 通过；type-check/build 待 node_modules 安装后验证
